# 📊 Marketing Campaign Performance Dashboard

An Excel-based data analytics project designed to analyze marketing campaign performance and transform raw campaign data into meaningful business insights through an interactive dashboard.

## 🎯 Project Overview

This project analyzes marketing campaign data across different **channels, regions, and dates** to understand campaign performance and key marketing KPIs.

The dashboard provides a clear view of spending, revenue, conversions, ROAS, budget allocation, and marketing funnel performance.

## 🔍 Key Analysis

* Spend vs Revenue Analysis
* Channel-wise ROAS Analysis
* Region-wise Conversion Analysis
* Budget Allocation across Marketing Channels
* Marketing Funnel: Impressions → Clicks → Conversions
* KPI and Campaign Performance Analysis
* Interactive filtering by Channel, Region, and Date
